# 嘉宾头像来源

本目录头像使用 DiceBear 的 Lorelei 风格本地生成并保存为静态 SVG，线上页面不会请求第三方头像接口。

- 风格：Lorelei
- 原始设计：Lisa Wischofsky
- 头像设计许可：CC0 1.0
- 生成工具：DiceBear
- 项目代码许可：MIT
- 风格说明：https://www.dicebear.com/styles/lorelei/
- DiceBear 项目：https://github.com/dicebear/dicebear

当前组合包含 7 个偏女性风格头像和 2 个偏男性风格头像。头像仅用于化名嘉宾的视觉区分，不代表真实人物。
